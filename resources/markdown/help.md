この Wiki の使い方と、本文に使える記法をまとめています。

## ページとリンク

この Wiki のページは階層を持たず、ページ同士をリンクでつないで使います。ページのタイトルがそのまま URL になります（空白は `_` になります）。

- **WikiLink**：`[[ページ名]]` と書くと、そのページへのリンクになります。表示する文字を変えたいときは `[[表示する文字|ページ名]]` と書きます。
- **赤リンク**：まだ無いページへのリンクは [[まだ無いページの例|赤色]] で表示されます。開くと「このページを作成する」ボタンが出ます。
- **このページへのリンク**：各ページの下に、そのページへリンクしているページの一覧が出ます。
- **目次**：見出しが 3 つ以上あるページでは、画面の右側に目次が出ます（広い画面のみ）。
- トップページは「ホーム」というページです。ホームは改名も削除もできません。

## タイトルの決まり

- 英字の大文字と小文字は区別しません。「Hello」と「hello」は同じページです。一方、カタカナの濁点の有無（「ハ」と「バ」）などは別のタイトルとして扱います。
- 全角の英数字は半角に、続けて入力した空白は 1 つにまとめられます。`_` は空白と同じ扱いです。
- `/ ? # [ ] |` は使えません。先頭のピリオド（`.env` など）と、末尾の `.php` も使えません。途中や末尾のピリオド（`Node.js`、`PHP 8.3` など）は使えます。
- システムが使う名前（`-`、`home`、`build`、`robots.txt` など）はタイトルにできません。

## 編集と履歴

- ページの作成・編集・削除にはログインが必要です。閲覧・検索・履歴の参照はログインしなくてもできます。
- 編集画面の「プレビュー」で、保存したときと同じ表示を確かめながら書けます。保存するときに「編集要約」を 1 行残すと、最近の更新と履歴に表示されます。
- **画像**：編集画面のツールバーの画像ボタン、画像の貼り付け、ドラッグ＆ドロップでアップロードできます。JPEG・PNG・GIF・WebP に対応しています。JPEG の撮影位置などの情報は、アップロード時に取り除かれます。
- **改名**：編集画面でタイトルを変えると改名できます。元のタイトルの URL やリンクは、新しいタイトルへ自動的に転送されます。
- **履歴**：保存するたびに版が残ります。履歴から過去の版の表示、版どうしの差分の確認、過去の版への復元ができます。復元は新しい版として保存されるので、それまでの版も消えません。
- **同時編集**：編集中に他の人が同じページを保存していた場合、保存時に知らせます。あなたの編集内容は残ったまま最新版の本文を確認できるので、必要なら取り込んでから保存し直してください。
- **削除**：削除したページは管理者が復元できます。削除と復元も履歴に残ります。削除したページと同じタイトルで、新しいページを作ることもできます。

## ページを探す

- **検索**：ヘッダーの検索欄（狭い画面では左上のメニューの中）から、タイトルと本文を部分一致で検索できます。空白で区切ると、すべての語を含むページを探します。英字の大文字と小文字は区別しません。
- **最近の更新**：左上のメニューから開きます。更新された順に、編集内容を一覧できます。
- **全ページ**：左上のメニューから開きます。すべてのページをタイトル順に一覧できます。

## Markdown 記法

本文は Markdown で書けます。HTML のタグはそのまま文字として表示されます。

| 記法                                           | 意味                                                      |
| ---------------------------------------------- | --------------------------------------------------------- |
| `# 見出し`                                     | 見出し（`#` の数でレベルが変わります。`#` 〜 `######`）   |
| `**太字**` / `*斜体*`                          | **太字**・_斜体_                                          |
| `~~打ち消し~~`                                 | ~~打ち消し線~~                                            |
| `- 項目`                                       | 箇条書き                                                  |
| `1. 項目`                                      | 番号付きリスト                                            |
| `- [ ] タスク` / `- [x] 完了`                  | チェックリスト                                            |
| `> 引用`                                       | 引用                                                      |
| `` `コード` ``                                 | インラインコード                                          |
| ` ``` ` で前後の行を囲む                       | コードブロック（` ```php ` のように言語名を付けられます） |
| `\| 列 \| 列 \|` の次の行に `\| --- \| --- \|` | テーブル（前後に空行が必要です）                          |
| `[表示](https://…)`                            | 外部リンク（新しいタブで開きます）                        |
| `![説明](画像のURL)`                           | 画像（編集画面でアップロードすると自動で入ります）        |
| `[[ページ名]]`                                 | Wiki 内のページへのリンク（WikiLink）                     |
| `[[表示\|ページ名]]`                           | 表示する文字を変えた WikiLink                             |
| `---`                                          | 区切り線                                                  |

## エディタのキー操作

- **Ctrl+B / Ctrl+I / Ctrl+K**：太字・斜体・リンクを挿入します（Mac では ⌘）。
- **Enter**：箇条書き・番号付きリスト・チェックリストの行で改行すると、次の行にも同じ記号が入ります。中身が空のまま Enter を押すとリストが終わります。
- **Tab / Shift+Tab**：リストの行を字下げ・字上げします。
- **[[**：入力すると既存ページの候補が出ます。↑↓ で選び、Enter か Tab で確定します。
